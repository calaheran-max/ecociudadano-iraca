CUADERNOS GUÍA 8 — CÓMO ABRIRLOS
=================================
1. Abre INICIO.html (doble clic) o:
   public/assets/cuadernos/INICIO.html

2. Elige el estudiante → se abre su cuaderno visual.

3. Pulsa "Imprimir / PDF" (Ctrl+P) para imprimir o guardar PDF.

Cada carpeta tiene:
  cuaderno.html          ← documento visual imprimible (USAR ESTE)
  cuaderno-completo.txt  ← texto plano de respaldo
